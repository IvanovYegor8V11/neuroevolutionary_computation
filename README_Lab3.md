# Лабораторная работа №3 — Вариант 7: HyperNEAT

Ноутбук: `Lab_3_variant7_HyperNEAT.ipynb`. Запуск в Google Colab: Runtime → Run all. Для быстрой проверки `QUICK_MODE=True`, для полного исследования `False`.

Вариант 7: HyperNEAT, сеть прямого распространения с одним скрытым слоем (CartPole-v1). CPPN с фиксированной структурой эволюционирует и генерирует веса сети 4→8→2 по геометрическим координатам. Полный NEAT-рост структуры CPPN не реализован — это упрощённая HyperNEAT-постановка.

Исследования: 2 seeds (7,37), random search baseline, абляция геометрии, изменения mutation_prob и mutation_sigma, проверка устойчивости к шуму наблюдений, неуспешные режимы, графики fitness и числа активных связей, сохранение и загрузка модели.

Бюджет одного обучения: 18×22=396 fitness-вызовов × 2 эпизода=792 эпизода. Полная серия содержит 10 обучающих запусков. Экспериментальные данные после запуска сохраняются в `lab3_hyperneat_results/`.

Зависимости устанавливаются первой ячейкой ноутбука в Google Colab. Синтаксис Python и формат ноутбука проверены локально; полное обучение локально не запускалось из-за отсутствия Gymnasium и недоступности установки через pip.
